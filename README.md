# MarketLens Assessment Submission

This repository contains submissions for both assessment tasks:

1. Product Scoping – MarketLens
2. Data Pipeline Building

## Repository Structure

- `/product-scoping` : Product strategy, scope, architecture, and wireframes for MarketLens
- `/pipeline-building` : Python-based API pipeline with BigQuery integration

## About MarketLens

MarketLens is an internal marketing insights platform that helps teams quickly understand marketing performance across channels by bringing campaign data and insights into one simple view.

## Tasks Included

### Task 1 – Product Scoping
Focused on defining:
- The product vision
- User problems
- MVP scope
- Architecture
- Workflows
- Wireframes
- Product tradeoffs

### Task 2 – Data Pipeline Building
Focused on:
- Extracting data from a public API
- Transforming and cleaning data
- Loading data into BigQuery
- Querying insights using SQL
- Production scaling considerations
